# AI Competitor Analyzer 🤖

A zero-friction, client-side tool designed to extract and align multilingual e-commerce specification sheets with one click. Say goodbye to manual copy-pasting.

## 🔗 Live Demo
[Try it here](https://bespoke-gnome-85b22b.netlify.app/)

## ✨ Features
- **One-click Extraction**: Instantly pull spec sheets from competitor pages.
- **Multilingual Alignment**: Automatically aligns specs across different languages.
- **Privacy-First**: All processing happens client-side (in your browser). No data is sent to any server.
- **Zero-Friction**: No installation, no login required.

## 🛠️ Tech Stack
- Pure HTML, CSS, and JavaScript (Vanilla)
- Deployed via Netlify

## 🚀 How to Use
1. Go to the [Live Demo](https://bespoke-gnome-85b22b.netlify.app/).
2. Paste the competitor URLs or spec text.
3. Click "Analyze" and get your aligned spec sheet instantly.
